# wpcodie.com

The WPCodie website: a static Astro + Preact site, deployed to Hostinger automatically on
every push to `main`.

```bash
npm install
npm run dev          # http://localhost:4321
npm run build        # output in dist/
npm run visual-diff  # check a change against the last commit, screen by screen
```

See [CLAUDE.md](CLAUDE.md) for where everything lives, how to make changes safely and how
deployment works.
